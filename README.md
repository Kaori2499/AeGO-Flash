# AeGO Flash 1.0.1

在 After Effects 时间线上导入、预览和渲染 Live2D 角色。动作与表情以独立片段编辑，支持声音口型、呼吸、眨眼和多帧渲染。

本次更新修复 AE 2024／2025 重启后效果控件的中文乱码，让初次加载与缓存加载采用一致的编码判定。导入窗口、渲染和工程标识保持不变。

适用于 Windows x64，目标宿主为 AE 2022 及以后版本，需要支持 Direct3D 11 的显卡。修复尚未在 AE 2022／2024／2025 实机验收；AE 2026 本发行包也仍待安装验证。

## 安装

1. 保存工程副本并关闭 AE。
2. 如已安装 `AeGOFlash`，先备份原文件夹再完整替换。如果插件目录中还有 `Live2DNativeAE` 文件夹，将它移出 `Plug-ins` 备份，避免同一效果重复加载。
3. 解压 `AeGOFlash-1.0.1-Windows-x64.zip`，把整个 `AeGOFlash` 文件夹复制到 AE 的 `Support Files/Plug-ins/`，例如：

   `C:\Program Files\Adobe\Adobe After Effects 2026\Support Files\Plug-ins\AeGOFlash\`

4. 完整保留 `AeGOFlash.aex`、`FrameworkShaders/`、`scripts/` 和 `licenses/`，不要只复制 `.aex`。Windows 要求管理员权限时按系统提示操作。
5. 启动 AE，在 **效果 → AeGO → AeGO Flash** 中添加效果。

卸载时关闭 AE，将 `AeGOFlash` 文件夹移出插件目录即可。安装包不包含模型或个人偏好。

## 导入与编辑

1. 创建与合成同尺寸的纯色层，添加 **AeGO Flash**。
2. 展开“模型与动画”，点击“导入模型”，选择 `.model3.json`。
3. 点击“导入动作与表情”。可分别选择动作、表情，或同时选择两者；支持搜索和外部文件。预览默认显示上半身，可切换全身、暂停或拖动进度。
4. 在“过渡时长”、“回弹幅度”、“添加位置”三张卡片中设置导入方式，点击“添加到时间线”。
5. 直接拖动、裁剪、复制或伸缩时间线片段。片段及标记使用素材名称，重叠区域自动过渡。

新建效果默认过渡 **30 帧**，30 fps 下为 1 秒，60 fps 下为 0.5 秒；设为 0 表示直接切换，短片段会自动缩短重叠。已保存的时长保留，确认导入后记住该模型层的时长。

回弹幅度有 **无／轻柔／明显** 三档，首次默认“明显”。确认含动作的导入后记住选择，跨模型和重启后沿用；取消或单独导入表情不修改记忆。表情保持淡入淡出，不受回弹幅度影响。

默认“接在上一动作后”，也可选择“从当前时间开始”。同时导入时表情与动作对齐；单独表情默认持续 3 秒。旧片段不会因新默认值改变，想更换片段的回弹幅度可重新导入该动作。

## 口型、呼吸和眨眼

- **声音与口型**：将配音放入合成，在“音频图层”选择轨道，再启用“声音同步口型”。用“口型灵敏度 (%)”调整开合幅度。此功能按音量驱动，不识别发音音素。
- **呼吸与眨眼**：分别启用“呼吸动画”和“自动眨眼”，可调整呼吸幅度、呼吸周期和眨眼间隔，并设置关键帧。两项默认关闭。
- **位置与大小**：调整模型缩放及水平、垂直偏移。
- **多帧渲染**：在 AE 首选项“内存与性能”中开启，AE 决定何时并发渲染。

## 使用须知

- 支持 Cubism 3+ 的 `.model3.json`、`.moc3`、`.motion3.json`、`.exp3.json`，不读取编辑工程 `.cmo3`。
- 模型、纹理、动作和表情保持外部引用，不嵌入 AE 工程，也不会自动加入“收集文件”；移动工程时一并保留素材及有效路径。
- 动作、表情没有固定导入数量上限；同一通道建议最多重叠两个片段。片段是引导图层，不会出现在成片中，请保留其识别标记。
- 一个已有片段的模型层固定使用同一模型；其他角色请新建模型层。导入包含资源与片段两个撤销步骤。
- 窗口预览仅显示角色，不包含 AE 的其他图层、效果或音轨；最终画面以合成视图为准。
- 输出带透明背景，原生 8 位；16 位输出由 8 位提升，不提供原生 32 位输出或逐项模型参数编辑。遮挡过渡不等同于物理防穿模。
- 多帧渲染最多并行计算 4 帧，实际速度和内存占用取决于模型、显卡与合成。本发行包尚无完整 AE 播放、导出及内存性能基准。

## 源码与许可

源码包为 `AeGOFlash-1.0.1-source.zip`，另附验证范围及性能机制说明。构建需要 Windows x64、Visual Studio 2022 C++ v143、Windows SDK、CMake、Adobe After Effects C++ SDK 和 Cubism SDK for Native 5-r.5。

```powershell
.\tools\Build.ps1 -AeSdk 'D:\SDK\AfterEffectsSDK' -CubismSdk 'D:\SDK\CubismSdkForNative-5-r.5'
```

SDK 和模型需自行取得，源码包不包含完整 SDK 或用户模型。第三方组件及许可见 [THIRD_PARTY.md](THIRD_PARTY.md)，许可原文位于安装包的 `licenses/`。
